# JLPT N5 線上模擬試題測試

一個純前端、零相依套件的 **JLPT N5（日本語能力試驗）線上模擬測驗** 網頁應用，支援行動裝置與桌面瀏覽器。

## 功能特色

- **164 題 N5 核心與實戰進階題庫**（每題皆附**題目漢字**、**完整中文詳解**與**重點整理**）：
  - **文字・語彙**：56 題（漢字読み、表記、文脈規定、言い換え類義，含長音／促音／濁音陷阱）
  - **文法**：52 題（文の文法、★ 排列組合題、文章の文法，含長段落與指示詞／轉折題）
  - **読解**：34 題（短文理解、約 200 字中篇閱讀、多條件情報検索）
  - **聴解**：22 題（含長對話轉折陷阱，支援瀏覽器 `ja-JP` 語音合成朗讀與逐字稿）
- **100 組固定模擬試卷（第 1 回 ～ 第 100 回）**：
  - 使用固定種子演算法（`mulberry32`）為每一回抽出均衡的 28 題（文字・語彙 10 ＋ 文法 10 ＋ 読解 5 ＋ 聴解 3）。
  - 支援 **隨機組卷** 與 **分科題庫練習**，並於瀏覽器 `localStorage` 自動記錄各回最高分。
- **雙測驗模式**：
  - **練習模式（即時詳解）**：作答後立即顯示對錯、題目漢字對照與答案解釋。
  - **模擬考試（計時交卷）**：限時 25 分鐘倒數計時，交卷後統一檢視成績與逐題詳解。
- **複習與行動裝置優化**：
  - 支援題目標記、錯題重練、錯題／標記篩選。
  - 支援鍵盤快捷鍵（數字鍵 `1`–`4` 選答，`←` / `→` 切換題目）與手機版底部黏滯操作列。

## 專案結構

- `index.html` — 主頁面與測驗介面結構
- `styles.css` — 響應式樣式表（支援桌面與行動裝置）
- `questions.js` — 基礎 N5 模擬試題庫（28 題）
- `questions_extra.js` — 擴充 N5 模擬試題庫（112 題）
- `questions_advanced.js` — 實戰進階 N5 題庫（24 題：中篇閱讀、多條件情報檢索、長對話轉折聽力等）
- `app.js` — 測驗邏輯、組卷演算法、計時器與語音朗讀控制

## 使用方式

直接用瀏覽器開啟 `index.html`，或在專案目錄下啟動任意靜態伺服器：

```bash
npx serve .
```
